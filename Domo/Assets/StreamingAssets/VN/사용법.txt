[ 미연시 콘텐츠 폴더 사용법 ]

게임을 실행하면 설정 화면이 먼저 나옵니다.
캐릭터(이름, 이미지, 전신/초상화) / 대사 파일 / 배경음을 고른 뒤 [출력하기] 를 누르세요.
전신/초상화는 A, B 캐릭터마다 따로 정할 수 있습니다.
(설정은 바로 저장되며, 이 폴더의 settings.json 에 기록됩니다)

■ 폴더 구성
  대사\      대사 파일 (메모장 txt). 여러 개 넣고 설정 화면에서 고를 수 있음
  이미지\    캐릭터·배경 이미지 (png, jpg)
  배경음\    배경음 (mp3, ogg, wav). 설정 화면에서 고른 파일을 게임 중 반복 재생
             ("없음" 을 고르면 재생 안 함)

  파일을 넣거나 고친 뒤 설정 화면으로 돌아오면 목록이 자동으로 갱신됩니다.
  게임 중에도 대사/이미지 파일을 저장하면 약 1초 안에 반영됩니다. (F5 = 수동 새로고침)


■ 대사 문법 (txt)

  # 로 시작하는 줄        주석
  빈 줄                   무시

  ● 대사
  A: 안녕!                            설정 화면의 A 캐릭터 (왼쪽)
  B: 반가워.                          설정 화면의 B 캐릭터 (오른쪽)
  유나: 안녕!                         설정 화면에서 지정한 이름으로 써도 됨
  A(가운데): 이쪽이야.                위치 지정 (left/center/right, 왼쪽/가운데/오른쪽)
  A(yuna_smile.png): 헤헤             이번 대사만 다른 이미지 (표정 변경)
  ???: 누구지?                        그 외 이름 → 이름표만 표시
  {player}: 나야.                     변수도 이름으로 사용 가능

  ● 나레이션
  콜론(:) 없는 줄은 이름표 없이 나레이션으로 표시됩니다.
  > 시간: 오후 5시                    앞쪽에 콜론이 있는 나레이션은 > 로 시작

  ● 명령
  [배경 bg_classroom.png]             배경 바꾸기 (이미지 폴더 기준)
  [배경 없음]                         배경 지우기
  [지우기]                            인물 모두 지우기
  [지우기 left]                       해당 위치 인물만 지우기

  ● 설정
  @변수 player = 모아                 대사 속 {player} 를 "모아" 로 바꿈
  @캐릭터 선생님 = teacher.png, center, #FFE08A
                                      A/B 외 추가 캐릭터 등록 (이미지, 위치, 이름 색)
  @캐릭터 반장 = leader.png, center, 초상화
                                      초상화로 출력 (4:3 처럼 비율을 써도 초상화)

  ● 꾸미기
  \n                                  줄바꿈
  <color=#FF0000>빨강</color>  <b>굵게</b>  <size=50>크게</size>


■ 게임 중 조작
  클릭 / Space / Enter    다음 대사
  ESC / 오른쪽 위 ✕        메뉴 (돌아가기 = 설정 화면 / 종료하기)
  F5                      파일 다시 불러오기
  마지막 대사 다음에 클릭하면 설정 화면으로 돌아갑니다.

■ 주의
  - 메모장 기본 저장(UTF-8) 그대로 쓰면 됩니다.
  - 대사 파일에 문제가 있으면 게임 화면에 "오류" 가 표시됩니다.
