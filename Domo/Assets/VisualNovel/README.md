# VN Player 사용 설명서

캐릭터 이미지 / 이름 / 대사(메모장 txt) / 배경음을 받아 미연시 화면처럼 출력하는 Unity 프로그램입니다.
실행하면 **설정 화면**이 먼저 나오고, 값을 정한 뒤 **출력하기**를 누르면 게임 화면으로 대사가 재생됩니다.

## 1. 빠른 시작

**빌드한 프로그램**
1. `VNPlayer.exe` 실행 → 설정 화면
2. `VN\대사` 폴더에 메모장(txt) 대사 파일, `VN\이미지` 에 그림, `VN\배경음` 에 음악을 넣음
3. 설정 화면에서 A/B 캐릭터 이름·이미지, 대사 파일, 배경음, 표시 방식을 고름
4. **출력하기 ▶**

**Unity 에디터**
1. `Assets/VisualNovel/Scenes/VNDemo.unity` 를 열고 Play
2. 콘텐츠는 `Assets/StreamingAssets/VN` 을 사용 (메뉴 `Tools > Visual Novel > Open Script Folder` 로 열기)

## 2. 폴더 구조

### 빌드 결과
```
VNPlayer\
├─ VNPlayer.exe
├─ VNPlayer_Data\
└─ VN\                    ← 이 폴더만 고치면 됩니다
   ├─ 대사\               대사 파일 (txt, json). 여러 개 넣고 설정 화면에서 선택
   ├─ 이미지\             캐릭터·배경 이미지 (png, jpg)
   ├─ 배경음\             배경음 (mp3, ogg, wav)
   ├─ settings.json       설정 화면 값 (자동 생성·저장)
   └─ 사용법.txt          메모장용 요약 설명
```

| 상황 | 동작 |
|---|---|
| 빌드 직후 | `Assets/StreamingAssets/VN` 내용이 exe 옆 `VN` 폴더로 자동 복사 |
| 같은 폴더에 다시 빌드 | **이미 있는 파일은 덮어쓰지 않음** → 빌드 폴더에서 고친 대사·이미지·설정 보존 |
| `VN` 폴더를 지운 채 실행 | 게임에 내장된 기본 데이터로 `VN` 폴더를 다시 만듦 |
| 예전 빌드의 `VN` 폴더에 `대사`/`이미지`/`배경음` 이 없음 | 실행 시 빠진 하위 폴더만 내장 데이터로 채움 |
| 에디터 | `Assets/StreamingAssets/VN` 을 읽고, 설정은 `%USERPROFILE%\AppData\LocalLow\<회사명>\<제품명>\vn_settings.json` 에 저장 |

### 이미지 경로 찾는 순서
대사 파일과 설정 화면에서 이미지 경로를 쓰면 아래 순서로 찾습니다.
1. 절대경로 (`D:\그림\yuna.png`)
2. `VN` 폴더 기준 (`이미지/yuna.png`)
3. `VN\이미지` 폴더 기준 → **파일 이름만 써도 됨** (`yuna.png`)
4. 그 밖에 웹 주소(`https://…`)와 Unity `Resources` 경로도 지원

- 캐릭터 이미지는 **배경이 투명한 PNG** 를 권장합니다.
- 배경 이미지는 비율을 유지한 채 화면을 꽉 채웁니다 (넘치는 부분은 잘림).

## 3. 설정 화면

변경한 값은 **바로 적용되고 자동으로 저장**됩니다. 탐색기에서 파일을 넣고 창으로 돌아오면 목록이 자동으로 갱신됩니다.
오른쪽 위 **콘텐츠 폴더 열기** 로 `VN` 폴더를 열 수 있습니다.

### 3-1. 캐릭터 설정 탭

| 항목 | 설명 |
|---|---|
| A 캐릭터 · 왼쪽 | 이름, 이미지 경로 (**찾아보기** 로 파일 선택 가능), 표시 방식 |
| B 캐릭터 · 오른쪽 | 이름, 이미지 경로, 표시 방식 |
| 미리보기 | 왼쪽 상자에 **실제로 출력될 모습**(초상화면 잘린 결과) 표시. 경로 아래에 `✓ 찾음` / `✕ 파일을 찾을 수 없습니다` 표시 |

**표시 방식 (캐릭터마다 따로 지정)**

| 방식 | 설명 |
|---|---|
| 전신 | 이미지 전체를 출력 (화면 바닥 기준, 화면 높이의 약 92%) |
| 초상화 | 이미지를 지정 비율로 잘라 크게 출력 (화면 바닥 기준, 화면 높이의 약 80%. 아랫부분은 대화창이 가림) |

초상화를 고르면 나오는 옵션:
- **자르기 비율** (가로 : 세로): `4:3` (기본) / `1:1` / `3:4`
- **자르는 위치**: 맨 위(얼굴 쪽) ↔ 맨 아래. 이미지가 비율보다 가로로 넓으면 가운데를 자릅니다.

예) A 는 전신, B 는 초상화처럼 섞어 쓸 수 있습니다. 대사에서 표정 이미지(`A(yuna_smile.png): …`)를 바꿔도 그 캐릭터의 표시 방식이 그대로 적용됩니다.

- 대사 파일에서 **`A:`** 또는 **A 이름**으로 시작하는 줄은 A 캐릭터(왼쪽), **`B:`** 또는 **B 이름**은 B 캐릭터(오른쪽)로 출력됩니다.
- 그래서 설정 화면에서 이름을 바꿔도 `A:` / `B:` 로 쓴 대사 파일은 고칠 필요가 없습니다.
- 이름표 색은 A 분홍(`#FFB3D9`), B 하늘색(`#A8D8FF`) 입니다.
- 이미지 경로를 비우면 이미지 없이 이름표만 표시됩니다.
- 찾아보기로 `VN\이미지` 안의 파일을 고르면 파일 이름만 저장되어, 폴더째 다른 PC로 옮겨도 그대로 동작합니다.

### 3-2. 대사 · 배경음 탭

**대사 파일**

| 방식 | 설명 |
|---|---|
| 폴더에서 선택 | `VN\대사` 폴더의 txt / json 파일을 ◀ ▶ 로 선택. **폴더 열기** 버튼 |
| 직접 첨부 | 다른 위치의 파일을 **찾아보기** 로 선택하거나 경로 입력. **해제** 로 취소 |

- 첨부한 파일이 있으면 폴더 선택보다 **우선**합니다. 첨부 파일이 사라지면 폴더 파일을 사용합니다.
- 아래에 `▶ 사용할 대사: 파일이름 · 대사 N개` 가 표시됩니다.
- 사용할 대사 파일이 없으면 출력하기를 눌러도 시작되지 않고 안내 문구가 나옵니다.

**배경음**

| 항목 | 설명 |
|---|---|
| 파일 선택 | **없음** 또는 `VN\배경음` 폴더의 mp3 / ogg / wav 를 ◀ ▶ 로 선택 (기본: 첫 번째 파일) |
| 미리 듣기 | 설정 화면에서 바로 들어보기 / 정지 |
| 볼륨 | 0 ~ 100% |

- 고른 파일은 게임 중 반복 재생됩니다. **없음**을 고르거나 폴더에 파일이 없으면 배경음 없이 실행됩니다.
- 다른 창을 클릭해도 끊기지 않습니다 (빌드 설정 *Run In Background* 켜짐).

### 3-3. 화면 설정 탭

전신 / 초상화는 **캐릭터 설정 탭**에서 캐릭터마다 지정합니다.

| 항목 | 값 |
|---|---|
| 인물 크기 | 50% ~ 150% |
| 대사 속도 | 느리게(초당 20자) / 보통(40자) / 빠르게(70자) / 즉시 |
| 전체 화면 | 끄면 1280×720 창 모드 (빌드에서만 적용) |

## 4. 게임 화면 조작

| 입력 | 동작 |
|---|---|
| 클릭 / 터치 / `Space` / `Enter` | 다음 대사 (글자가 출력 중이면 즉시 전체 표시) |
| `ESC` 또는 오른쪽 위 **✕** | 메뉴 팝업 열기 / 닫기 |
| 메뉴 → **돌아가기** | 설정 화면으로 (배경음 정지) |
| 메뉴 → **종료하기** | 프로그램 종료 |
| `F5` | 대사·이미지 파일 다시 불러오기 |

- 메뉴가 열려 있는 동안에는 대사가 넘어가지 않고 배경음도 일시 정지됩니다.
- 마지막 대사 다음에 한 번 더 클릭하면 설정 화면으로 돌아갑니다.
- 게임 중에 대사 파일이나 이미지를 저장하면 **약 1초 안에 자동으로 다시 불러오며**, 보던 대사 위치를 유지합니다. (배경음 파일 교체는 설정 화면으로 돌아갔다가 다시 시작해야 적용)
- 말하지 않는 캐릭터는 자동으로 어둡게 표시됩니다.

## 5. 대사 파일 문법 (txt)

### 기본 규칙
- 한 줄 = 하나의 명령 또는 대사. 위에서부터 순서대로 진행됩니다.
- 빈 줄, `#` 또는 `//` 로 시작하는 줄(주석)은 무시됩니다.
- 앞뒤 공백은 무시됩니다.
- 메모장 기본 저장(UTF-8) 그대로 쓰면 됩니다.

### 한눈에 보기

| 문법 | 의미 |
|---|---|
| `A: 대사` / `B: 대사` | 설정 화면의 A / B 캐릭터 대사 |
| `이름: 대사` | 설정 화면 이름 또는 `@캐릭터` 로 등록한 이름이면 해당 캐릭터, 아니면 이름표만 |
| `이름(옵션, …): 대사` | 위치·이미지·이름표를 지정한 대사 |
| `콜론 없는 문장` | 나레이션 (이름표 없음) |
| `> 문장` | 강제 나레이션 |
| `[배경 경로]` / `[배경 없음]` | 배경 변경 / 제거 |
| `[지우기]` / `[지우기 위치]` | 인물 모두 / 해당 위치만 제거 |
| `@변수 키 = 값` | 대사·이름의 `{키}` 를 값으로 치환 |
| `@캐릭터 이름 = 이미지, 위치, #색, 초상화` | A/B 외 추가 캐릭터 등록 (표시 방식 생략 시 전신) |

### 5-1. 대사

```
A: 안녕!                          ← A 캐릭터 (왼쪽)
B: 반가워.                        ← B 캐릭터 (오른쪽)
유나: 안녕!                       ← 설정 화면에서 A 이름이 "유나" 라면 A 와 같음
???: 누구지?                      ← 등록 안 된 이름 → 이름표만, 화면의 인물은 그대로
{player}: 나야.                   ← 변수도 이름으로 사용 가능
```
- 콜론은 반각 `:` 와 전각 `：` 모두 인식합니다.
- 이름은 20자 이하여야 합니다 (더 길면 나레이션으로 처리).

**옵션** (괄호 안, 쉼표로 구분, 순서 상관없음)

| 옵션 | 예 | 설명 |
|---|---|---|
| 위치 | `A(가운데): …` | `left` `center` `right` / `왼쪽` `가운데` `오른쪽` / `l` `c` `r` / `좌` `중앙` `우` |
| 이미지 | `A(yuna_smile.png): …` | 이번 대사에 쓸 이미지 (표정 변경) |
| 이름표 | `A(이름=???): …` | 이번 대사만 이름표를 다르게 |
| 조합 | `A(오른쪽, yuna_angry.png): …` | 여러 옵션 함께 |

**위치 결정 순서**
1. 괄호에 위치를 쓰면 그 위치
2. 생략하면 그 캐릭터가 **마지막으로 섰던 위치**
3. 처음 등장이면 기본 위치 (A 왼쪽, B 오른쪽, `@캐릭터` 는 지정한 위치)
4. 그것도 없으면 가운데

> 다른 위치로 옮겨도 원래 자리의 이미지는 자동으로 지워지지 않습니다. `[지우기 left]` 처럼 지워 주세요.

### 5-2. 나레이션
```
방과 후, 노을이 비치는 교실.
> 시간: 오후 5시          ← 앞쪽(20자 안)에 콜론이 있으면 > 로 시작
```

### 5-3. 명령 (`[ ]`)
명령은 **바로 다음 대사가 나올 때** 함께 적용됩니다.

| 명령 | 별칭 | 설명 |
|---|---|---|
| `[배경 경로]` | `[bg 경로]` `[background 경로]` | 배경 변경 |
| `[배경 없음]` | `[배경 none]` | 배경 제거 |
| `[지우기]` | `[clear]` | 모든 인물 제거 |
| `[지우기 left]` | `[clear right]` 등 | 해당 위치 인물만 제거 (여러 번 쓰면 여러 자리) |

### 5-4. 설정 (`@`)

**변수**
```
@변수 player = 모아
```
- 대사·이름표의 `{player}` 가 `모아` 로 바뀝니다. `@var` 도 가능.
- 실행 인자 `-vnvar player=홍길동` 이 있으면 그 값이 우선합니다.

**추가 캐릭터** (A/B 외 세 번째 인물 등)
```
@캐릭터 선생님 = teacher.png, center, #FFE08A
@캐릭터 미스터리 = shadow.png, right, 이름=???
@캐릭터 반장 = leader.png, center, 초상화
@캐릭터 점원 = clerk.png, right, 3:4
```
- `=` 오른쪽 항목은 순서 상관없고 생략 가능: 이미지 / 기본 위치 / 이름 색(`#RRGGBB`) / `이름=화면에 보일 이름표` / 표시 방식(`전신` · `초상화` · 비율 `4:3` 처럼 쓰면 그 비율의 초상화)
- `@인물`, `@char`, `@character` 도 가능
- 그 캐릭터의 **첫 대사보다 위**에 적어야 합니다.
- 설정 화면의 A/B 와 같은 이름을 `@캐릭터` 로 등록하면 **설정 화면 값이 우선**합니다.

### 5-5. 텍스트 꾸미기

| 문법 | 결과 |
|---|---|
| `\n` | 줄바꿈 |
| `<color=#FF5555>빨강</color>` | 글자색 |
| `<b>굵게</b>` / `<i>기울임</i>` | 굵게 / 기울임 |
| `<size=50>크게</size>` | 글자 크기 (기본 40) |

## 6. 예제 대사

`VN\대사\샘플 대사.txt` 와 같은 형식입니다.

```
# 설정 화면: A = 유나 (yuna.png), B = 하루 (haru.png)

@변수 player = 모아
@캐릭터 선생님 = teacher.png, center, #FFE08A

[배경 bg_classroom.png]
방과 후, 노을이 비치는 교실.

A: 어, {player}! 아직 안 갔어?
B: <color=#A8D8FF>나도</color> 있는데… 왜 나는 못 본 척해?
A(yuna_smile.png): 하하, 미안미안. 그럼 셋이서 같이 갈까?

???: 거기 너희들!
[지우기]
선생님: 하교 시간 지났다. 얼른 집에 가라.

{player}: (혼났다…)

[배경 bg_street.png]
[지우기]
우리는 함께 밤거리로 나섰다.

> 시각: 오후 7시 30분

B(가운데): 오늘 하루도 수고했어, {player}.\n내일 또 보자.
```

> 기본 제공 이미지는 `bg_classroom.png`, `bg_street.png`, `yuna.png`, `haru.png` 4개입니다.
> `yuna_smile.png`, `teacher.png` 처럼 없는 이미지는 해당 인물만 표시되지 않고(로그에 경고), 대사는 정상 진행됩니다.

## 7. 빌드

1. `File > Build Profiles` (또는 Build Settings) → Windows
2. Build Settings 맨 앞에 `VNDemo` 씬이 등록되어 있습니다.
3. 빌드 후 exe 옆에 `VN` 폴더가 자동으로 복사됩니다 (`Editor/VNBuildPostprocess.cs`).

관련 프로젝트 설정:
| 설정 | 값 | 이유 |
|---|---|---|
| Player > Run In Background | 켜짐 | 다른 창을 눌러도 배경음·진행이 멈추지 않음 |
| Active Input Handling | Both | 클릭·키 입력은 Input System 패키지 사용. 설정 화면 입력칸(uGUI InputField)의 한글 IME 가 구 Input API 를 쓰므로 함께 켜 둠 (Input System 만 켜면 이름 칸에 한글 입력이 안 됨) |

## 8. 실행 인자

```bat
VNPlayer.exe -vnfolder "D:\내콘텐츠"
VNPlayer.exe -vnvar player=홍길동 -vnvar school=모아고
```

| 인자 | 설명 |
|---|---|
| `-vnfolder <경로>` | `VN` 대신 다른 콘텐츠 폴더 사용 (그 안에 `대사` / `이미지` / `배경음` 구성) |
| `-vnvar 키=값` | 변수 지정 (대사 파일의 `@변수` 보다 우선, 여러 번 사용 가능) |
| `-vnscript <경로>` | 대사 파일 지정. **설정 화면(VNLauncher) 없이 VNPlayer 만 쓸 때만 적용**되며, 설정 화면을 거치면 설정 화면에서 고른 파일이 사용됩니다. |

## 9. 코드에서 직접 호출 (API)

```csharp
using VisualNovel;

// ── 설정 화면 없이 바로 재생 ──
VNPlayer player = FindAnyObjectByType<VNPlayer>();
var st = VNSettings.Load();           // 또는 new VNSettings { charAName = "유나", ... }
player.ApplySettings(st);             // 캐릭터 A/B, 표시 방식, 속도, 대사 파일 적용
StartCoroutine(player.Begin());       // 대사 파일을 불러와 처음부터 재생

// ── 대사 불러오기 ──
player.LoadScriptText("A: 안녕!\nB: 반가워.");          // txt 문법 또는 JSON 문자열
StartCoroutine(player.LoadScriptFile("대사/chapter2.txt"));  // VN 폴더 기준 상대경로 또는 절대경로
player.Play();                        // 처음부터
player.JumpTo(5);                     // 6번째 대사로 (배경/인물 상태 재현)
player.Next();                        // 다음 대사

// ── 화면 요소 개별 설정 ──
player.SetBackground("bg_street.png");                 // 또는 Sprite
player.SetCharacter(VNPlayer.Slot.Left, "yuna.png");   // 또는 Sprite
player.ClearCharacter(VNPlayer.Slot.Left);
player.ClearAllCharacters();
player.SetNickname("유나", new Color(1f, 0.7f, 0.85f));
player.SetDialogue("안녕, {player}!");
player.Say("유나", "안녕!");
player.SetVariable("player", "모아");
player.SetDialogueBoxVisible(false);

// ── 표시 방식 ──
// 전신/초상화는 캐릭터(VNCharacterDef)마다 지정
player.presetCharacters[0].portrait = true;        // 초상화
player.presetCharacters[0].portraitAspect = 4f / 3f; // 가로/세로
player.presetCharacters[0].portraitFocus = 0f;     // 0 = 맨 위
player.characterScale = 1f;
player.ApplyDisplaySettings();                     // 현재 화면의 인물에 다시 반영

// ── 상태 / 이벤트 ──
int index = player.CurrentIndex;
bool typing = player.IsTyping;
bool error = player.HasError;
player.inputEnabled = false;          // 클릭으로 대사 넘김 막기
player.onLineShown.AddListener(i => Debug.Log($"{i}번 대사"));
player.onFinished.AddListener(() => Debug.Log("끝"));
```

`VNLauncher` (설정 화면) 공개 메서드: `ShowMenu()`, `StartGame()`, `Quit()`

## 10. JSON 형식 (선택)

txt 대신 JSON 도 지원합니다. 확장자가 `.json` 이거나 내용이 `{` 로 시작하면 자동으로 JSON 으로 읽습니다.

```json
{
  "variables":  [ { "key": "player", "value": "모아" } ],
  "characters": [ { "id": "선생님", "nickname": "선생님", "image": "teacher.png", "nameColor": "#FFE08A" } ],
  "lines": [
    { "background": "bg_classroom.png", "nickname": "none", "text": "방과 후의 교실." },
    { "character": "유나", "position": "left", "text": "어, {player}!" },
    { "clearCharacters": true, "clearSlots": "left,right", "text": "..." }
  ]
}
```
- `lines` 항목: `background`, `character`, `nickname`, `image`, `position`, `text`, `clearCharacters`, `clearSlots`
- `"none"` = 제거/숨김, 빈 값 = 이전 상태 유지
- 설정 화면의 A/B 캐릭터는 `character` 에 **설정한 이름**으로 지정합니다 (JSON 에서는 `A` / `B` 별칭 미지원).

## 11. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 출력하기를 눌러도 시작되지 않음 | 사용할 대사 파일이 없음. `VN\대사` 에 txt 를 넣거나 파일을 첨부 |
| 게임 화면에 **"오류"** 이름표 | 대사 파일을 못 읽었거나 대사가 하나도 없음. 고쳐서 저장하면 자동 복구 |
| 이미지 경로 아래 **✕ 파일을 찾을 수 없습니다** | 파일 이름 오타, 또는 `VN\이미지` 밖에 있음 → 찾아보기로 선택 |
| A/B 캐릭터가 아니라 이름표만 나옴 | 대사의 이름이 `A` / `B` / 설정 화면 이름과 다름 (띄어쓰기 포함 확인) |
| 특정 줄이 무시됨 | 알 수 없는 명령/옵션. 로그(`%USERPROFILE%\AppData\LocalLow\<회사명>\<제품명>\Player.log`)의 `N번째 줄:` 경고 확인 |
| 나레이션이 이름표 달린 대사로 나옴 | 앞쪽 20자 안에 콜론이 있음 → 줄 앞에 `>` |
| 이동한 캐릭터가 두 자리에 보임 | 이전 자리는 자동으로 지워지지 않음 → `[지우기 위치]` |
| 초상화에서 얼굴이 잘림 | 캐릭터 설정 → 해당 캐릭터의 자르는 위치를 위쪽으로, 또는 비율을 `3:4` 로 |
| 인물이 바닥에서 떠 보임 | 이미지 아래쪽에 투명한 여백이 있는지 확인 (이미지 아래 끝이 화면 바닥에 맞춰짐) |
| 배경음이 안 나옴 | `VN\배경음` 에 파일이 있는지, 배경음이 **없음**으로 되어 있지 않은지, 볼륨 확인 (설정 화면의 미리 듣기로 테스트) |
| 한글이 깨짐 | 메모장에서 **UTF-8** 로 저장. ANSI(CP949) 읽기도 시도하지만 환경에 따라 지원되지 않을 수 있음 |
| 다시 빌드했는데 대사·이미지가 예전 그대로 | 빌드 폴더의 기존 파일은 덮어쓰지 않음 (의도된 동작). 새 기본 데이터를 쓰려면 빌드 폴더의 `VN` 폴더를 지우고 다시 빌드 |
